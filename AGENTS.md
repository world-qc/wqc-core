# AGENTS.md (Agent Interaction & Development Protocol)
This document defines the operational constraints and coding standards for AI agents and automated systems interacting with this repository.

## Development Constraints
All agents (AI or Human) contributing to this repository MUST adhere to the following environment rules:
- **Language & Comments**: All source code, documentation, and inline comments must be written in English.
- **Rust Version**: Target Rust 1.95+. Avoid nightly features unless explicitly requested.
